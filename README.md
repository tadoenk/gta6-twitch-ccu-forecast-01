# gta6-twitch-ccu-forecast-01

A deterministic forecast program for Grand Theft Auto VI's launch-day Twitch viewers, hours 2 to 24. It anchors on the known hour-1 viewers and scales by the median and spread of log-ratios to hour 1 across past rolling-midnight launches, emitting five quantiles per hour. Standard library only, no network, byte-identical across runs.
